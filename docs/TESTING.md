# Testing

Run `pytest -q` at repository root for API behavior tests against isolated SQLite state. Run `ruff check apps/api/voicesphere tests`. Run frontend `npm ci`, then `npm run lint` (TypeScript static check), `npm run build`, and browser E2E from `apps/web`. For E2E, install Chromium once with `npx playwright install chromium`, then run `npm run test:e2e`. The browser suite mocks API responses and tests all seven section URLs by direct open and reload, sidebar navigation, and Back/Forward history. Backend tests cover login, identity, dashboard counts, verification gating, tenant isolation, ticket creation, agent publishing, voice mock disclosure, LiveKit token dispatch claims, and session termination. Latest local evidence: 8 backend tests passed; 2 browser tests passed (all seven routes); Ruff, TypeScript, and production build passed; npm audit reported 0 vulnerabilities. The installed Node 20.20.2 runtime produced engine warnings (project requires >=22.22), so use Node 22.22+ on Windows. Provider audio, PostgreSQL, Docker, Terraform, and cloud deployment are not currently exercised.
