# AI evaluation plan

No LLM/RAG provider is currently wired; therefore there are no AI quality measurements to report. Planned evaluation should use synthetic/redacted test cases for identity verification, order intent, tool selection, unsupported answer abstention, prompt-injection resistance, citation correctness, escalation decisions, and response latency. Track exact model/prompt versions, tool-call arguments, ground-truth outcome, and human reviewer scores. Never treat a successful mock session as an AI pass.
