# Local setup

Requirements: Python 3.12+, Node 22.22+ for the selected frontend dependency set, and optionally Docker Desktop. Copy `.env.example` to `.env`; use a generated secret (for example Python `secrets.token_urlsafe(48)`). Default local API database is SQLite. From `apps/api`, install `requirements-dev.txt`, run `alembic upgrade head`, run `python -m voicesphere.seed`, then start `uvicorn voicesphere.main:app --reload --port 8000`. From `apps/web`, run `npm ci && npm run dev`. Sign in using the synthetic demo user shown in the main README. To verify routes on Windows, install Chromium once with `npx playwright install chromium`, then run `npm run test:e2e` (the test command starts/reuses the local Next server and mocks API responses).

The provided seed data is fictitious. Customer verification sample: `jordan.lee@example.test` and final four `4821`; order `NS-10482`. The protected order tool requires a recent verification token. Run tests from repo root: `pytest -q`.\n\nFor provider-backed audio, configure a LiveKit project and set `VOICE_MODE=livekit`, `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, and the three provider API keys in `.env`. Install `services/voice-agent/requirements.txt` in a separate Python 3.12+ environment, then from `services/voice-agent` run `python agent.py dev` (or `start`). Open the Voice playground and grant microphone access. LiveKit will dispatch the `voicesphere-support` worker. Customer verification/order/ticket tools are deliberately not connected to the voice agent; the worker must not claim to complete those actions. Provider-backed voice was not tested without credentials.
